# 小学1〜6年生向けおすすめ本 × カーリル蔵書照会ツール

小学1〜6年生向けにおすすめの本を学年で絞り込み、[カーリル(calil.jp)](https://calil.jp) で
指定した地域の図書館に所蔵がある本だけを候補として表示する静的Webツールです。ビルド不要、`index.html` をブラウザで開くだけで動作します。

## 公開URL

https://ekemkk-2012.github.io/book-finder/

GitHub Pagesで公開しているため、ログインなしでリンクを知っている人なら誰でも(スマホ含む)
閲覧でき、カーリルAPIの実際の通信も行えます(Claude Artifactは通信制限のあるサンドボックス内で
動作するため、図書館検索・蔵書確認機能が使えません。そのためこのリポジトリを別途作成しています)。

## 使い方

1. 上記URLをブラウザで開く(あるいは任意の静的サイトホスティングにこのリポジトリの内容を
   デプロイして使う)。
2. **APIキーの入力は不要です。** このツールにはあらかじめ共有のカーリルAPIキーが
   埋め込まれているため、友人にリンクを共有しても、初回登録時・毎セッション時の
   いずれもAPIキーを入力させる必要はありません(ヨンデミーなどのアプリと同様の
   仕組みです)。図書館の検索・蔵書確認もそのまま動作します。
   - カーリルの蔵書チェックAPIの利用上限(1時間あたり1000冊分)は
     **アクセス元(≒利用者)ごと**にカウントされる仕様のため、この共有キーを
     大勢で同時に使っても、お互いの利用上限を奪い合うことはありません。
   - 図書館を選んでいない間は、各本の「カーリルで見る →」リンクから書誌ページを
     開いて手動で確認できます(ただしその場合は開いたページ側で毎回地域を入力する
     必要があります。詳細は下記の「お気に入り図書館について」を参照)。
3. 「都道府県」をドロップダウンで選び(デフォルトは東京都)、「市区町村」を自由入力
   (ワードサーチ)して「この地域の図書館を検索」を押す。
   - カーリルの図書館API(`https://api.calil.jp/library`)で、その市区町村の
     図書館システムと、そこに属する個別の図書館(例: くにたち中央図書館、
     くにたち北市民プラザ図書館 など)が一覧表示されます。各図書館名はカーリルの
     該当ページ(`https://calil.jp/library/{libid}/{正式名称}`)にリンクしています。
   - 「図書館名で絞り込み」に館名の一部(例: 「中央」)を入力すると絞り込めます。
   - 確認したい図書館システムにチェックを入れてください(通常は市区町村ごとに1つ)。
   - 選んだ地域・図書館は、この端末のブラウザに自動的に記憶されます(`localStorage`)。
     次回このページを開いたときは、自動的に前回の地域で検索・選択済みの状態になります。
     **この記憶は端末+ブラウザごとの保存**のため、別のスマホ・PCで開いた場合は、
     最初の1回だけ検索・選択をやり直す必要があります(以後はその端末でも記憶されます)。
4. 「学年」のチェックボックス(1〜6年生、複数選択可)で本のリストを絞り込めます。
   選んだ学年は`localStorage`に自動保存され、次回開いたときも引き継がれます
   (未選択時のデフォルトは全学年)。「発行年」をドロップダウンで選ぶと
   (デフォルト2005年以降)、さらに絞り込まれます。タイトル・著者名でのワードサーチ
   (絞り込み)も可能です。
   - 学年と年齢の対応(このツールでの定義): 1年生=7歳・2年生=8歳・3年生=9歳・
     4年生=10歳・5年生=11歳・6年生=12歳、として、年齢別に本を紹介している
     [絵本ナビ](https://www.ehonnavi.net/)のようなリソースも学年に読み替えて
     参照できるようにしています。この対応表は `books.js` の`AGE_TO_GRADE`に
     定義されています。
5. 図書館を選ぶと、表示中の候補の所蔵が自動的に確認され(カーリルの蔵書チェックAPI)、
   **選んだ図書館に所蔵がない本は候補から外れて、次の本に自動で入れ替わります**
   (入れ替わった本もまた確認され、表示中が所蔵ありの本だけになるまで続きます)。
   各本の貸出状況(貸出可/貸出中など)・館ごとの内訳・予約リンクは表の中に直接
   表示され、館名はカーリルの該当ページにリンクしています。「図書館名で絞り込み」を
   入れると、その館に所蔵がある本だけが候補になります。確認結果はページを開いている
   間だけ保持され、「所蔵を再確認する」で最新の状況を取り直せます。
6. 読んだことがある本や苦手だとわかっている本は、各行の「読んだ」「苦手」ボタンで
   一覧から非表示にできます。非表示にした本は「非表示にした本」欄にまとめて表示され、
   いつでも「リストに戻す」で再表示できます。この記録はブラウザの`localStorage`に
   保存されるため、次回開いたときも保持されます。
7. 「パンどろぼう」「おしりたんてい」「ふしぎ駄菓子屋 銭天堂」「ノラネコぐんだん」
   「大ピンチずかん」「給食番長」「ざんねんないきもの事典」のように複数巻あるシリーズは、
   本のリストの上にある「シリーズで一括操作」から、シリーズ丸ごと「読んだ」「苦手」に
   したり、まとめて元に戻したりできます(有名シリーズは既読のことが多いため)。

## お気に入り図書館について(補足)

カーリルには、ログインした上で最大10件の図書館を「お気に入り」として登録できる
機能(https://calil.jp/settings)があります。これを設定しておくと、calil.jp上の
検索結果ページなどでその図書館の状況が自動的に優先表示されるようになりますが、
以下の理由からこのツールでは**前提にしていません**。

- カーリルの[OpenURL](https://calil.jp/doc/api_openurl.html)(各本の「カーリルで
  見る →」リンクが使っている仕組み)は、ISBNなどから書誌ページへリンクするだけの
  受信専用の機能で、地域や図書館をURLに渡すパラメータがありません。
- そのため、リンク先のページでその都度地域を入力する必要があり、お気に入り
  登録がその画面に反映されるかどうかは、ブラウザのログイン状態や、カーリル側の
  ページ仕様に依存します。
- 確実に「この画面の中で」貸出状況を表示したい場合は、上記の手順2にある共有
  APIキーによる方法をおすすめします。こちらは実際に動作確認済みです。

## 書籍リストの管理(books.csv)

書籍リストの正本は `books.csv` です。`books.js` はそこから自動生成するため、直接編集しないでください。

| 列 | 内容 |
| --- | --- |
| isbn / title / author / publisher / pubdate / pages / series | 書誌情報(pubdateは`YYYY-MM-DD`、seriesは単独作品なら空) |
| grades | 対象学年を`|`区切りで(例: `1|2|3`) |
| verify_status | `verified`(ISBNチェックサム+2つ以上の独立した情報源でISBN・書名・版を照合済み) / `single_source`(情報源1つのみ。要再確認) / `unverified`(未照合) / `wrong`・`duplicate_edition`(誤り・別版の重複。`books.js`には出力しない) |
| verify_sources / verify_note | 照合に使った情報源(`|`区切り)と補足 |

```sh
python3 tools/check_books.py    # ISBNチェックサム・重複・必須項目・books.jsとの一致を検査し、照合状況と学年別冊数を表示
python3 tools/build_books_js.py # books.csv から books.js を生成
```

## 補足

- 本のリストは `books.js` にシードデータとして同梱しています(初期表示は2005年以降
  発行の本。一部は青少年読書感想文全国コンクールの課題図書にも選ばれています)。各本には
  [絵本ナビ](https://www.ehonnavi.net/)や出版社サイトで確認したページ数(`pages`)、
  シリーズ名(`series`、単独作品は`null`)、対象学年(`grades`、例:`[1,2,3]`)を
  付与しています。ページ数を見れば、10ページ程度の絵本と100ページを超える児童書が
  混ざっていることが一覧で分かります。追加したい本があれば `books.js` に直接追記するか、
  画面下部の「本を追加で検索」(Google Books API使用、ページ数・シリーズ名・対象学年は
  空欄)から検索して追加できます。
- 都道府県ドロップダウンの選択肢とカーリルのURL用スラッグ(例: 東京都→tokyo、
  市区町村一覧ページ`https://calil.jp/library/{スラッグ}/{市区町村}`用)の対応表は
  `prefectures.js` にあります。
- 図書館の検索(`api.calil.jp/library`)・蔵書チェック(`api.calil.jp/check`)は
  いずれもAPIキーが必要ですが、このツール専用の共有キー(`app.js`の`SHARED_APPKEY`)を
  あらかじめ埋め込んでいるため、利用者が別途取得・入力する必要はありません。
  JSONP経由でブラウザから直接呼び出しており、サーバーは不要です。ネットワーク環境
  によっては`calil.jp`へのアクセスがブロックされている場合があります。
- カーリルAPI仕様書の「カーリルへのリンク」の定めに従い、APIで取得した図書館名・
  貸出状況を表示する際は、必ずカーリルの該当ページ(`https://calil.jp/library/{libid}/...`
  または `https://calil.jp/library/search?s={systemid}&k={libkey}`)へリンクしています。
- Google Booksでの追加検索は、ブラウザ/ネットワーク環境によってはCORS制限で
  動作しないことがあります。その場合でも、シードリストと蔵書確認は問題なく
  利用できます。
- 独自のAPIキーを入力した場合や、選択した地域や図書館・「読んだ/苦手」の記録は、
  いずれもこの端末のブラウザ内(`localStorage`)にのみ保存され、外部には送信
  されません。複数の端末(PC・スマホなど)で使う場合は、各端末で最初の1回だけ
  地域の設定などをやり直す必要があります(APIキーは共有キーのため設定不要です)。

## デプロイの仕組み

このリポジトリの内容(`index.html`以下)は、`main`ブランチへのpushをトリガーに
GitHub Actions(`.github/workflows/deploy-pages.yml`)経由でGitHub Pagesへ自動デプロイ
されます。フォークして自分のGitHubアカウントで公開する場合は、リポジトリの
Settings → Pages → Source を「GitHub Actions」に設定してください。
